## 📜 Reglas de Citación (Para Agentes)

> **REGLA:** Cuando trabajes con este proyecto, SIEMPRE cita las fuentes de la siguiente manera:

### 1. Para dependencias directas (componentes)
```
[Nombre](URL) - Descripción
```
Ejemplo:
```
[Hyprland](https://github.com/hyprwm/Hyprland) - Gestor de ventanas Wayland
[Waybar](https://github.com/Alexays/Waybar) - Barra de estado
```

### 2. Para scripts y configuraciones basadas en otros
```
Inspirado por [Autor/Proyecto](URL)
```
Ejemplo:
```
# Inspirado por end-4/dots-hyprland
# https://github.com/end-4/dots-hyprland
```

### 3. Para plugins de Neovim
```
{nombre} ({autor}) - Descripción | MIT
```
Ejemplo:
```
lazy.nvim (folke) - Plugin manager | MIT
```

### 4. Formato en commits/mensajes
```
feat/component: description
Refs: [Hyprland](https://github.com/hyprwm/Hyprland), [EWW](https://github.com/elkowar/eww)
```

### 5. En código (comentarios)
```bash
# Fuentes: [Hyprland](https://github.com/hyprwm/Hyprland), [Waybar](https://github.com/Alexays/Waybar)
```
